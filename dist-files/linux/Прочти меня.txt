Foxray — VPN-клиент (VLESS Reality, Hysteria2) поверх sing-box
===============================================================

Как запустить
1. Распакуй архив куда удобно, например в ~/Programs:
       tar -xzf Foxray-*-linux-x86_64.tar.gz -C ~/Programs
   Папка должна лежать на обычном диске Linux (не на флешке/разделе Windows),
   иначе sing-box не получит права на сеть.
2. Запусти ./foxray (или сначала ./install-menu.sh — появится в меню приложений).
3. При первом подключении система один раз спросит пароль. Foxray выдаёт
   sing-box право создать сетевой адаптер VPN (TUN) и ставит правило polkit,
   чтобы VPN мог направлять DNS через себя без пароля при каждом подключении
   (/etc/polkit-1/rules.d/49-foxray.rules). После обновления Foxray пароль
   спросят ещё раз — у нового файла sing-box прав пока нет.
   Если окна с паролем нет — выполни в терминале из папки Foxray:
       sudo setcap cap_net_admin,cap_net_bind_service,cap_net_raw+ep ./sing-box

Если программа не запускается — не хватает библиотек (обычно уже есть):
   Ubuntu/Debian: sudo apt install libgtk-3-0 libxdo3 libayatana-appindicator3-1

Как подключиться
1. Скопируй ссылку на сервер (vless://… или hy2://…) или подписку (https://…).
2. Вкладка «Серверы» → «+». Ссылка из буфера подставится сама → «Добавить».
3. На вкладке «Главная» нажми переключатель.

Полезное
- Локальная сеть (роутер, принтеры, NAS) по умолчанию работает мимо VPN.
- Свои правила — вкладка «Правила». Программы в Linux пишутся как
  process:firefox или полным путём /usr/bin/firefox.
- Трей: в GNOME значок виден только с расширением «AppIndicator»
  (в Ubuntu уже включено). Если значка нет — поставь в «Настройках»
  кнопку «Закрыть» → «В панель задач». Повторный запуск Foxray
  показывает уже открытое окно.
- Zapret (Discord с голосом и YouTube без VPN): «Настройки» → «Zapret» → «Скачать»,
  потом «Подобрать стратегию». Zapret работает от root — при включении система
  спросит пароль (один раз за запуск Foxray). Нужны пакеты nftables и pkexec
  (в Ubuntu обычно уже стоят), если нет:
     Ubuntu 22.04+/Debian 12+: sudo apt install nftables pkexec
     Ubuntu 20.04/Debian 11:   sudo apt install nftables policykit-1
     Fedora:                   sudo dnf install nftables polkit
- Обновление: «Настройки» → «Обновление» → «Обновить». Foxray скачает новую
  версию и перезапустится; серверы и настройки останутся.
- Все данные (серверы, настройки) хранятся в этой же папке.
  Чтобы перенести Foxray на другой ПК — просто скопируй папку.

Удаление
1. «Настройки» → выключи «Запускать при входе в систему».
2. Закрой Foxray (кнопка «Выход» в меню значка или в настройке «Закрыть»).
3. Удали папку и, если запускал install-menu.sh,
   файл ~/.local/share/applications/foxray.desktop
4. Правило DNS: sudo rm /etc/polkit-1/rules.d/49-foxray.rules
   (на старых системах — /etc/polkit-1/localauthority/50-local.d/49-foxray.pkla)
