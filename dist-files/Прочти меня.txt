Foxray — VPN-клиент (VLESS Reality, Hysteria2) поверх sing-box
===============================================================

Как запустить
1. Распакуй папку Foxray куда удобно (например, в C:\Programs\Foxray).
   Не запускай прямо из архива.
2. Запусти Foxray.exe. Windows спросит права администратора — это нужно,
   чтобы создать сетевой адаптер VPN.
3. Если Windows покажет «Система Windows защитила ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае» (программа не подписана).

Как подключиться
1. Скопируй ссылку на сервер (vless://… или hy2://…) или подписку (https://…).
2. Вкладка «Серверы» → «+». Ссылка из буфера подставится сама → «Добавить».
3. На вкладке «Главная» нажми переключатель.

Полезное
- Локальная сеть (роутер, принтеры, NAS) по умолчанию работает мимо VPN.
- Свои правила — вкладка «Правила»: какие сайты и программы идут напрямую,
  через VPN или блокируются.
- Свой DNS (AdGuard Home, Pi-hole) — «Настройки» → «Свой DNS-сервер».
- Все данные (серверы, настройки) хранятся в этой же папке.
  Чтобы перенести Foxray на другой ПК — просто скопируй папку.

Удаление
1. «Настройки» → выключи «Запускать вместе с Windows».
2. Закрой Foxray (правый клик по значку → «Выйти из Foxray»).
3. Удали папку.
